# Escape Room

This personal project utilizes basic Java features to create a text-based, navigatable Escape Room.
I utilize classes, methods, and strings and incorporate a gameboard to display the game.


The game has multiple objects that the player can interact with

At any point during the game, you can type "help" to get a list of commands you can use.
Then, you can choose the command, prompting an action, like examining an item, or stop examining.

The goal of the game is to find the cure. Once the cure is found and you've taken the cure, you have completed the escape room.
